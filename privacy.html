Harbourline Enquiry Agent

Privacy policy

Effective 9 November 2026

Demonstration project. Harbourline Plumbing & Heating is fictional. The app is used only with a Google account created for this demo and with made-up test data. Please don't send real personal information to the demo inbox.

Who runs this app

The Harbourline Enquiry Agent ("the app") is a portfolio project built and operated by Raynor (github.com/Raynor1511). It is not a commercial service.

Google user data the app accesses

Google serviceWhat the app doesWhy
GmailReads incoming messages in the demo inbox. Sends replies, and applies labels to messages it has handled.To process enquiries and, after a person approves a draft, send the reply.
Google CalendarReads free and busy times on the demo bookings calendar. Creates tentative events.To offer appointment times and, after approval, hold the chosen slot.

The app does not access contacts, Drive files or any other Google data.

How the data is used

  • The text of each enquiry is sent to Anthropic's Claude API so it can be classified and a reply drafted. Anthropic processes this under its commercial API terms and does not use API data to train its models.
  • Enquiries, drafts, approval decisions and an audit log are stored in a database (Supabase, hosted in the EU) so every step can be reviewed.
  • No reply is sent and no booking is made without a person approving it first.

What the app never does

  • Sell Google user data, or share it with anyone other than the processors named above.
  • Use Google user data for advertising.
  • Use Google user data to develop, improve or train AI or machine-learning models.
  • Let people read the data, except the operator reviewing drafts and logs for this demo.

The Harbourline Enquiry Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Demo data is kept only while the demonstration is running, and is deleted within 90 days of the demo ending. You can revoke the app's access to a Google account at any time at myaccount.google.com/permissions.

Security

Access keys are stored outside the source code. The tools the AI uses can only read data, and the database account they use has read-only permissions.

Changes and contact

Changes to this policy will be posted on this page with a new effective date. For questions, open an issue on GitHub.
